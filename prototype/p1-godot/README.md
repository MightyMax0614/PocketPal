# PocketPal P1.8 — Godot Free Character Prototype

비용이 들지 않는 Godot 4.7.1 기반 2D 캐릭터 시제품입니다. Godot은 MIT 라이선스이며 에디터·런타임·배포 로열티가 없습니다.

## 구현된 기능

- 참고 이미지 방향의 작은 구형 머리, 짧은 목, 긴 몸통, 가는 팔·다리
- 호흡과 미세 체중 이동
- 불규칙 눈 깜빡임
- 손가락/마우스 시선 추적
- 말하기 입 움직임
- 쓰다듬기, 손 흔들기, 점프, 궁금함, 기쁨, 졸림
- 일정 시간 후 먼저 말을 거는 최소 Soul 동작
- 얼굴·모자·옷·배지 스타일 슬롯

## 실행

1. Godot 4.7.1 Standard를 설치합니다.
2. Godot Project Manager에서 이 폴더의 `project.godot`을 가져옵니다.
3. ▶ 실행 버튼을 누릅니다.

## 아이폰 테스트

- 빠른 브라우저 검증: Web export에서 **Thread Support를 끈 단일 스레드**로 내보냅니다.
- 최종 휴대기기: macOS와 Xcode에서 iOS 네이티브 export를 사용합니다.
- Web은 편리하지만 네이티브 iOS보다 성능과 안정성이 낮으므로 최종 구조로 단정하지 않습니다.

## 현재 한계

- 코드와 Godot 장면은 작성했지만 이 저장 환경에는 Godot 실행 파일이 없어 실제 엔진 실행 검증은 아직 GitHub Actions 또는 로컬 Godot에서 필요합니다.
- 외형은 첫 번째 벡터 바디이며, 참고 이미지와의 최종 비율·표면 품질은 실제 화면을 보고 보정해야 합니다.
- 현재 파츠는 회전형 리그입니다. 다음 단계에서 Skeleton2D/Polygon2D 메시 변형으로 팔·몸 연결부를 더 자연스럽게 개선합니다.
