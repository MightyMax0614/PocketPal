# PocketPal P1 Web Prototype

설치 없이 PC와 아이폰 브라우저에서 실행하는 첫 번째 소프트웨어 시제품입니다.

## 현재 구현

- 480 × 640 비율의 PocketPal 화면
- 캐릭터 눈 깜빡임과 대기 애니메이션
- AI가 먼저 말을 거는 시뮬레이션
- 터치·마우스로 돌리는 가상 클릭휠
- 키보드 방향키와 Enter 조작
- 전면·후면 카메라 전환
- 그림 업로드와 선물 미리보기
- 브라우저 `localStorage` 기반 기억 저장
- 한국어 음성 합성 지원 브라우저에서 간단한 음성 출력

## 실행 방법

### GitHub Pages

저장소의 GitHub Pages를 `main` 브랜치의 `/root`로 활성화하면 루트 `index.html`이 이 시제품으로 이동합니다.

카메라는 보안상 HTTPS 환경에서 가장 안정적으로 동작합니다.

### PC에서 직접 실행

단순 화면은 `index.html`을 열어도 되지만, 카메라 시험은 로컬 웹 서버를 권장합니다.

```bash
cd prototype/p1-web
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 조작

- 클릭휠을 원을 따라 드래그: 메뉴 이동
- 가운데 `선택`: 메뉴 열기·항목 선택·이전 메뉴
- 방향키: 메뉴 이동
- Enter 또는 Space: 선택
- Esc: 친구 화면으로 이동

## 현재 한계

- 실제 AI API는 아직 연결하지 않음
- 음성 인식은 아직 연결하지 않음

- 기억은 현재 브라우저 내부에만 저장
- 실제 하드웨어 클릭휠과 NAS는 아직 연결하지 않음
