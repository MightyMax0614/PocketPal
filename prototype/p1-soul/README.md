# PocketPal P1.6 Soul Lab

캐릭터 그래픽과 분리해 PocketPal의 핵심 행동을 먼저 검증하는 아이폰용 로컬 시제품입니다.

## 검증 항목

- 아이 이름과 PocketPal 이름
- 성격과 말투
- 기분, 에너지, 호기심, 친밀도
- 좋아하는 것, 중요한 일, 최근 이야기, 사람 기억
- 기억과 시간대에 따른 자발 발화
- 간단한 로컬 대화 반응
- iOS 음성 합성
- 보호자 데이터 내보내기, 가져오기, 삭제

## 개인정보 원칙

현재 버전은 모든 데이터를 브라우저 `localStorage`에 저장합니다. 서버, NAS, 클라우드로 전송하지 않습니다.

## 자발 발화

- 테스트 모드: 마지막 상호작용 후 20초
- 실제 사용 모드: 마지막 상호작용 후 10분
- 테스트 모드 반복 간격: 45초
- 실제 사용 모드 반복 간격: 30분

화면이 보이는 상태에서만 작동합니다. iOS Safari가 백그라운드에 있을 때는 웹 타이머가 중지될 수 있으므로, 최종 기기의 자발 발화는 운영체제 서비스 또는 기기 상주 프로세스로 이전해야 합니다.
