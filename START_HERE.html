실행 파일이 열리지 않을 때

터미널 앱을 열고 bash 를 입력한 뒤, 끝의 공백 다음에 Start_PocketPal.command 파일을 터미널 안으로 드래그하고 Enter를 누릅니다. 파일을 이동했거나 폴더 이름이 달라도 이 방식으로 실행할 수 있습니다.

다운로드 폴더에 기본 이름으로 풀었다면 다음 명령도 사용할 수 있습니다.

bash "$HOME/Downloads/PocketPal_Mac_Test/Start_PocketPal.command"

Python이 없다는 안내가 나오면 Python 공식 macOS 설치 페이지에서 Python 3.9 이상의 macOS 설치 프로그램을 설치한 뒤 다시 실행하세요. 별도 pip/npm 패키지·Docker·Xcode는 필요하지 않습니다. 현재 Python 3.13 또는 3.14 계열을 사용할 수 있습니다.

이번 픽셀 버전에서 달라진 점

캐릭터를 Pixel Frog의 Pixel Adventure 원본 2종으로 교체했습니다. 원본은 32×32 픽셀이며, 대기 11프레임·달리기 12프레임·점프/낙하 포즈를 CSS로 재생합니다. 원화를 다시 그리지 않았습니다. 쓰다듬기와 인사는 원본 동작에 회전·작은 점프·기호를 조합한 반응이며, 잠자는 전용 원화는 없습니다. 선택한 캐릭터는 두 아이별로 저장하고 백업합니다. 외형 최종 확정은 직접 보고 결정합니다. 그림은 2D 파츠 착용까지 구현했으며, 실제 3D 변환·GLB·AR·음성 입력·NAS 연결·백그라운드 알람은 다음 단계입니다.

카메라는 직접 켠 동안만 사용하고, 그림은 선물로 저장할 때만 보관합니다. 한국어 음성은 설치된 로컬 음성만 사용하며 기본값은 꺼짐입니다. 보호자 비밀번호가 없는 시험판이므로 우선 부모가 시험용 데이터로 확인하세요.

기억 파일: ~/Library/Application Support/PocketPalMacLab/pocketpal.sqlite3. 실행 폴더를 옮겨도 유지됩니다. 두 아이의 데이터는 하나의 데이터베이스에서 프로필별로 분리됩니다. 이전 웹 시험판의 브라우저 저장값은 자동으로 옮기지 않습니다.
