# 캐릭터 동작 초안 0.4 · 2026-09-08

정지 도트 시안만 있던 오리지널 가운데 H1·D1·A3·A4에 대기·걷기·대화·수면 프레임을 추가했습니다. 실제로 재생되는 원화 프레임을 비교하고, 34종 전체의 진행 상태를 한 화면에서 파악하기 위한 변경입니다.

## 결과

- 4종 × 4동작 × 6프레임 = 96프레임.
- 캐릭터별 96×96px 고정 셀, 576×384px 아틀라스 및 4개 동작 스트립.
- 캐릭터별 동일 배율과 발 기준선 보정. 생성 원본, 수정 프롬프트, 경계 좌표와 해시 보관.
- 34종 통합 비교 화면: 오리지널 4종 동작 + 6종 정지 시안 + Pixel Frog 24종.
- 동작별 속도, 일시정지, 좌우 뒤집기, 확대, 작은 화면 크기에 맞춘 표시.
- 별도 설치 없이 여는 `Character_Catalog.html`과 4종 GIF 미리보기.

## 이번에 실행한 확인

- 새 생성 자산 96프레임 모두 감지된 원화 경계가 자르기 경계 내부에 있음.
- 16개 동작마다 6프레임과 서로 다른 프레임 해시 확인.
- 실행 데이터에 10개 중복 없는 오리지널 ID, 애니메이션 4종, 정지 6종, Pixel Frog 24종 확인.
- 전체 재생 항목의 PNG 크기·프레임 수·마지막 프레임까지의 이미지 경계 확인.
- Pixel Frog 원본 66개 비교 클립의 SHA-256이 이전 메타데이터와 일치.
- 변경 JavaScript, 생성 데이터, 오프라인 HTML에 포함된 스크립트 구문 검사 통과.
- 오프라인 HTML의 외부 스크립트·스타일 의존성 없음 확인.
- 생성된 원화와 재생 아틀라스, 4종 미리보기 정지 프레임을 이미지로 확인.
- GIF 48프레임 전체 디코딩과 종료 마커 확인.
- `git diff --check` 통과.

브라우저 조작 시험과 사용자의 M1/Safari 실기 시험은 이번 턴에 실행하지 않았습니다. 실제 사용자 기기에서의 재생·터치·파일 열기는 검증 필요입니다. 기존 Mac Lab 서버·데이터 처리 코드는 변경하지 않았으므로 이번 작업을 서버·기억·AI 대화의 새 시험 결과로 표시하지 않습니다.
