# 카메라 따라 하기 0.5 · 2026-09-08

## 실행

1. `codex/character-collection-20260908` 브랜치의 최신 폴더 전체를 내려받습니다.
2. `Start_PocketPal.command` 실행 후 `http://127.0.0.1:8765/mirror/index.html`을 엽니다.
3. 사람·티라노·하마·돼지·핑크·개구리 중 친구를 선택합니다.
4. 먼저 시연 버튼을 눌러 반응을 봅니다. 실제 카메라 인식 결과로 표시하지 않습니다.
5. **카메라 켜고 따라 하기** → 카메라 허용 → 얼굴·어깨·손이 보이게 앉습니다.

이 화면은 기존 Mac Lab에 추가된 동작 시험입니다. 기존 대화·기억·선물 화면과
34종 캐릭터 모음도 유지합니다. 파일을 직접 더블클릭하는 `file://` 방식은 지원하지 않습니다.

첨부된 Adrien Ninet 게시물은 입력·마우스에 반응하는 아바타와 배경 디자인 작업에
관한 내용입니다. 캡처에는 무료 아바타 저장소 이름·URL이 없어 특정 저장소를
설치했다고 표시하지 않습니다. 반응 방식을 기존 PocketPal 캐릭터에 직접 적용했습니다.
Limora AI MCP나 유료 서비스를 실행하거나 결제하지 않았습니다.

## 처리·저장

- 필요한 JS·WASM·모델 약 28.4 MB를 실행 폴더에 포함합니다. 카메라를 켤 때 CDN을 호출하지 않습니다.
- 영상·자세 좌표는 현재 브라우저 메모리 안에서만 처리합니다. 녹화·서버 업로드·영구 저장·추적 로그를 만들지 않습니다.
- 마이크를 요청하지 않습니다. 정해진 문장 반응에도 외부 AI API를 사용하지 않습니다.
- 끄기·탭 숨김·페이지 종료·카메라 연결 종료·처리 오류 때 스트림과 Worker를 종료합니다.
- 늦게 허용된 이전 카메라 스트림은 화면에 연결하지 않고 즉시 닫습니다.
- 서버는 기존 기본값인 localhost 바인딩을 유지합니다. 대화·기억 페이지의 스크립트 정책은 유지하고 `/mirror/`에만 로컬 WASM 실행을 허용합니다.
- 기존 두 아이의 기억·사진을 이번 화면에 연결하지 않습니다. 향후 대화 연동 시 보낼 관찰 정보와 보관 범위를 별도로 구현합니다.

## 자동 확인

실행 환경: 제공된 Linux / Python / Node. 실제 사용자의 macOS·Safari에서 실행한 결과가 아닙니다.

- `node --test tests/test_motion.mjs`: 9개. 신뢰도 낮은 관절 배제, 거울 방향, 흔들림 억제, 추적 상실 초기화, 지연된 권한/모델 응답, 중지·오류 시 자원 종료.
- `python3 -m unittest discover -s tests -p 'test_mac_lab.py' -v`: 기존 16개 + 신규 2개. 저장·백업·아이별 분리와 카메라 화면 자산/MIME/CSP/경로 접근 확인.
- JS 구문, 로컬 의존성 존재, 런타임·모델 SHA-256, 모델 번들 내부 파일, Git 공백 오류 확인.

브라우저 시험 주소 연결이 실패하여 화면 렌더링·WASM 모델 초기화·실제 카메라 추론은
이번 환경에서 검증하지 못했습니다. 자동 검사는 동작 판정과 자원 수명주기를 검증하며,
실제 모델 인식 정확도나 맥북 프레임률의 통과 결과를 대신하지 않습니다.
