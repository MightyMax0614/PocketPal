# PocketPal – AI Companion & 3D Gift System
## Master Project Specification

- 문서 버전: v0.1
- 작성일: 2026-08-02
- 문서 목적: ChatGPT 프로젝트 참고용 마스터 사양서
- 우선순위: 두 자녀용 완성 시제품 2대 제작
- 판매·양산: 실제 사용성 검증 이후에만 검토

---

## 1. 프로젝트 역할 지침

이 프로젝트에서 AI는 PocketPal의 공동 제품기획자, 하드웨어·소프트웨어 설계자, AI 개발 파트너, 기술 PM으로 행동한다.

다음 원칙을 유지한다.

- 이전 대화에서 확정한 내용을 유지하고 같은 질문을 반복하지 않는다.
- 한국어로 쉽고 정확하게 설명한다.
- 미검증 내용은 반드시 `추정`, `잠정`, `검증 필요`로 표시한다.
- 사용자가 `진행해`, `해봐`, `시작해`라고 하면 같은 확인 질문을 반복하지 않고 현재 단계의 실제 결과물을 만든다.
- 아이디어를 계속 늘리기보다 현재 단계에서 만들고 검증할 항목을 우선한다.
- 실제 치수와 데이터시트로 검증하고 콘셉트 이미지를 제작용 CAD로 단정하지 않는다.
- 국내 재고와 빠른 배송을 우선하며, 국내에 없을 때만 해외 부품을 제안한다.
- GitHub가 작동하지 않아도 다운로드 가능한 파일, ZIP, 문서, 커밋 단위로 진행한다.

## 2. 제품 정의

PocketPal은 아이와 대화하고, 기억하고, 먼저 말을 걸며, 함께 성장하는 휴대형 AI 친구다.

단순한 AI 스피커나 다마고치가 아니라 다음을 결합한 제품이다.

- 화면 속에서 생활하는 AI 캐릭터
- 아이와의 장기 기억과 관계 형성
- 전·후면 카메라를 통한 현실 세계 이해
- AR을 통한 현실 공간 등장
- 원형 클릭휠을 이용한 조작과 교감
- 아이의 그림을 3D 선물로 만들어 캐릭터에게 주는 시스템
- 로컬 기기·NAS 중심의 가족 데이터 보호

초기 목표는 판매가 아니라 사용자의 두 자녀를 위한 완성도 높은 시제품 2대를 제작하는 것이다.

## 3. 핵심 사용자 경험

### 3.1 AI 친구

- 아이의 이름, 성향, 중요한 날, 취향을 기억한다.
- 사진, 대화, 장소, 이벤트를 장기 기억한다.
- 사용자가 질문할 때만 답하는 것이 아니라 상황에 따라 먼저 말을 건다.
- 인터넷이 없어도 캐릭터, 알람, 간단한 대화, 핵심 기억이 작동한다.
- 시간이 지나면서 말투, 성격, 관계, 반응이 변화한다.
- 아이가 기기를 켰을 때 단순 앱이 아니라 친구가 깨어나는 느낌을 제공한다.

### 3.2 카메라 경험

전면 카메라:

- 아이 얼굴과 표정 감지
- 사용자가 화면을 보고 있는지 확인
- 셀카와 캐릭터 합성 사진
- 영상통화 확장 가능성
- 아이의 감정 상태 추정 보조

후면 카메라:

- 사물·그림·책·환경 인식
- 사진·영상 촬영
- AR용 현실 공간 인식
- 아이가 그린 그림 촬영
- 주변에서 본 것을 AI와 함께 이야기하는 기능

### 3.3 클릭휠 경험

클릭휠은 메뉴 조작용 장치이면서 캐릭터와 교감하는 감성 입력 장치다.

예시:

- 원형 회전: 목록 이동, 볼륨, 시간 이동
- 느린 회전: 캐릭터 쓰다듬기
- 빠른 회전: 놀이 또는 특수 반응
- 중앙 버튼: 선택·깨우기·사진 촬영
- 상·하·좌·우 클릭: 메뉴, 이전, 다음, 재생·일시정지
- 길게 누르기: 상황별 보조 기능
- 진동 피드백: 입력 확인과 감정 반응

## 4. 3D 선물 시스템

### 4.1 목표

아이가 종이, 태블릿, 스마트폰 등에 옷이나 액세서리를 그리고 PocketPal에게 선물하면 AI 캐릭터가 실제로 착용하고 반응한다.

### 4.2 기본 파이프라인

1. 아이의 그림 촬영 또는 업로드
2. 배경 제거
3. 선 정리와 색상 보정
4. 액세서리·의상 종류 인식
5. 2D 이미지를 3D 형태로 변환
6. 메시 두께 생성
7. 크기·비율·방향 보정
8. 캐릭터 체형과 부착점에 맞춤
9. UV와 텍스처 생성 또는 보정
10. 필요 시 리깅과 변형 처리
11. GLB 또는 glTF로 저장
12. 스마트폰·PocketPal에서 미리보기
13. 아이가 `선물하기`
14. 캐릭터가 착용하고 감정적으로 반응
15. 추억과 선물 기록을 장기 기억에 저장

### 4.3 초기 구현 범위

처음부터 자유형 의상 전체를 완벽하게 구현하지 않는다.

초기 대상:

- 모자
- 안경
- 배지
- 브로치
- 가방
- 목걸이
- 손에 드는 작은 소품

후속 확장:

- 상의
- 하의
- 전신 의상
- 신발
- 움직이는 장식
- 캐릭터 체형에 따라 변형되는 의상

### 4.4 처리 장치 역할

아이폰·Open Minis:

- 그림 촬영
- 업로드
- 미리보기
- 선물하기
- 간단한 편집

PC·NAS:

- 배경 제거
- 이미지 정리
- 종류 인식
- 2D→3D 변환
- 메시·UV·텍스처·부착점 보정
- GLB 저장
- 가족 데이터 보관

클라우드:

- 로컬에서 처리하기 어려운 고급 3D 생성
- 복잡한 이미지 이해
- 고성능 모델 사용
- 필요한 경우에만 선택적으로 사용

### 4.5 참고 기술

- img2threejs 계열 프로젝트
- 이미지 기반 3D 생성
- Blender 자동화
- GLB/glTF 파이프라인
- 배경 제거 모델
- 세그멘테이션
- 3D Gaussian Splatting 또는 NeRF는 필요 시 참고
- 액세서리 부착점 기반 시스템
- 캐릭터 스켈레톤·리깅

특정 기술에 종속되지 않으며, 실제 결과 품질과 구현 난이도를 기준으로 선택한다.

## 5. 확정 외형 사양

### 5.1 전체 크기

- 높이: **104 mm**
- 너비: **62 mm**
- 목표 두께: **12.0 mm**
- 최대 허용 두께: **12.5 mm**
- 목표 무게: **120 g 이하**
- 형상: 세로형 휴대 기기
- 디자인 방향: iPod Classic에서 영감을 받되 그대로 복제하지 않음
- 모서리: 부드러운 라운드
- 주머니와 작은 손에 들어가는 크기

### 5.2 전면

- 약 2.8인치 세로형 IPS 디스플레이
- 최소 해상도 480 × 640
- 터치는 보조 입력
- 원형 클릭휠이 주 입력
- 클릭휠 외경 약 40 mm
- 중앙 버튼 약 15 mm
- 전면 카메라는 화면 상단 베젤 안에 숨김
- 렌즈가 외부에서 두드러지지 않게 함
- 검은색 스모크 광학창 또는 동등한 구조 검토

### 5.3 평면 클릭휠 구조

확정 조건:

- 클릭휠, 중앙 버튼, 전면 케이스는 평상시 같은 높이
- 표면에서 튀어나오지 않음
- 누를 때만 아래로 이동
- 돌출 테두리 금지
- 필요하면 무광 질감, 미세 인쇄, 재질 차이로 위치 구분
- 상·하·좌·우·중앙 물리 클릭
- 원형 정전식 터치 감지
- 진동 피드백 포함

잠정 치수:

- 외경: 40 mm
- 중앙 버튼: 15 mm
- 링 폭: 약 8~10 mm
- 버튼 이동량: 약 0.2~0.5 mm 범위 검토
- 표면 오버레이: 약 0.5~0.8 mm 검토

### 5.4 후면

- 후면 카메라 필수
- 좌측 상단 또는 상단 영역 배치
- 렌즈만 0.5~1 mm 돌출 허용
- 스마트폰형 소형 카메라 모듈 우선
- 스피커는 후면 또는 하단 측면 방출 구조 검토
- 로고·제품명은 최소화

### 5.5 포트와 입출력

- USB-C: 하단 중앙
- 마이크: 2개
- 스피커: 스마트폰형 1개
- 진동 모터: 1개
- Wi-Fi
- Bluetooth
- 전원·잠금 버튼은 측면 검토
- 헤드폰 단자는 제외
- LTE, NFC, UWB, GPS는 초기 제외 또는 후속 검토

### 6.2 센서 우선순위

필수:

- 6축 IMU
- 주변 밝기 센서
- 배터리 온도 감시
- 사용자 감지 또는 근접 감지 가능성 검토

후속:

- 지자기 센서
- 기압 센서
- GPS
- NFC
- UWB

### 6.3 카메라 구조

- 전면·후면 카메라 모두 유지
- 두 카메라를 앞뒤로 정확히 겹치지 않도록 배치
- 개발용 일반 카메라 모듈은 최종 두께 기준으로 사용하지 않음
- 최종형은 FPC 기반 스마트폰형 초박형 모듈 우선
- 전면은 고정초점 2~5MP 검토
- 후면은 5~8MP, 자동초점 우선 검토
- 동시에 촬영할 필요가 없으면 전환 방식 허용
- AR과 얼굴 인식 전환 지연은 실제 시험 필요

### 6.4 배터리 목표

잠정 목표:

- 1,800~2,200 mAh
- 약 4 mm 두께급 검토
- USB-C 충전
- 보호회로와 온도 감시
- 실제 사용 반나절 목표
- 대기 하루 이상 목표

주의:

- 실제 사용시간은 화면 밝기, 카메라, Wi-Fi, 음성, AI 호출 빈도에 따라 크게 달라짐
- 맞춤 배터리는 P1·P2 검증 전 구매 금지
- 초기 시험은 USB 전원 또는 보조배터리로 진행

## 10. 부품 조사 원칙

대한민국 내 재고와 빠른 배송을 최우선으로 한다.

우선 확인 판매처:

- 디바이스마트
- 아이씨뱅큐
- 엘레파츠
- 메카솔루션
- 로봇사이언스몰
- RS코리아
- 국내 공식 총판
- 신뢰 가능한 국내 네이버스토어

부품 후보마다 반드시 제시할 정보:

- 정확한 제품명
- 국내 재고 여부
- 가격
- 배송 예상
- 크기와 두께
- 무게
- 전압
- 연결 방식
- 개발 시험용인지 최종형 후보인지
- 국내 대체품
- 주의점
- 실제 데이터시트 출처

구매 원칙:

- 모든 부품을 한꺼번에 구매하지 않는다.
- 기존 PC, 스마트폰, 웹캠, 마이크, 스피커로 먼저 시험한다.
- 단계별 최소 부품만 구매한다.
- P1과 P2 검증 전 고가 개발보드, 맞춤 배터리, 전용 PCB 구매 금지.
- 해외 부품은 국내 대체품이 없고 꼭 필요할 때만 제안한다.
- 해외 배송이 긴 부품은 초기 검증 경로에서 제외한다.

## 11. 설계 검증 원칙

모든 중요 결정은 다음 상태로 표시한다.

- `확정`: 변경하지 않는 기본 요구
- `잠정`: 현재 최선안이지만 부품 검증에 따라 변경 가능
- `검증 필요`: 실제 시험이나 데이터시트 확인 전에는 단정하지 않음
- `제외`: 현재 단계에서 하지 않음
- `후속`: 이후 단계에서 검토

임의로 삭제하면 안 되는 요구:

- 전면 카메라
- 후면 카메라
- 베젤 안에 숨겨진 전면 카메라
- 평면 클릭휠
- 중앙 버튼 포함 5방향 클릭
- 클릭휠과 전면 케이스의 동일 높이
- 104 × 62 mm 기준 외형
- 12.0 mm 목표, 12.5 mm 최대
- 3D 선물 시스템
- 로컬·NAS 우선 데이터 구조
