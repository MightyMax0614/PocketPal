# PocketPal Pixel Edition 0.3 — 캐릭터 교체

2026-09-08. 기존 기하 도형 캐릭터를 Pixel Frog의 **Pink Man / Ninja Frog** 원본으로 교체했다.
최종 외형 확정 전, 맥북에서 원본 픽셀 애니메이션과 교감을 평가할 실행판이다.

## 바로 확인하기

1. `Character_Preview.html`을 Safari 또는 Chrome으로 연다. Python·Unity·npm·인터넷이 필요 없다.
2. 핑크 친구 / 개구리 친구를 바꾸고 쓰다듬기·인사·달리기·점프·휴식을 눌러 본다.
3. 모자 그림을 올리면 움직임을 따라 붙는다. 미리보기에서는 저장하지 않는다.
4. 대화·기억·선물 저장까지 시험하려면 `Start_PocketPal.command`를 실행한다.
5. 이전 실행판이 켜져 있으면 그 터미널에서 Control+C로 종료한 뒤 새 실행 파일을 연다.

## 바뀐 내용

| 항목 | 구현 |
|---|---|
| 원화 | Pixel Frog 원본 PNG를 그대로 사용. 다시 그리거나 색을 바꾸지 않음 |
| 재생 | 32×32 셀, 대기 11프레임, 달리기 12프레임. 기본 20 FPS |
| 점프 | 원본 Jump / Fall 포즈 + 포물선 형태의 상하 이동 |
| 쓰다듬기·인사 | 원본 대기 프레임 + 작은 움직임 + 하트/음표 반응 |
| 휴식 | 느린 대기 루프. 전용 수면 원화는 포함하지 않음 |
| 자율 행동 | 가끔 짧게 달리거나 점프. 끄기와 전체 멈춤 제공 |
| 캐릭터 선택 | 두 아이별 파일 저장, 서버 재시작·백업·복원 지원 |
| 그림 선물 | 기존 머리·얼굴·배지·손·몸통 5개 위치 유지 |
| 부착 추적 | 원본 프레임의 높이 변화와 이동·방향·점프를 따라 위치 보정 |
| 오프라인 | 모든 이미지·코드 동봉. 미리보기 HTML은 한 파일로 내장 |

그림 선물은 **2D 이미지 부착**이다. 몸을 감싸는 옷, 자연스러운 앞뒤 가림,
3D 메시·리깅·GLB·AR는 아직 구현하지 않았다. 기존 기억 데이터의 위치와 저장 구조를 유지했고,
이전 버전 백업에 캐릭터 선택값이 없으면 아이별 기본 캐릭터를 추가한다.

## 확인한 결과

- 서버 통합 검사 **16개 통과**. 기존 저장·아이별 분리·동시 변경·백업 복원 검사 14개와
  캐릭터 선택 저장/복원, 이전 백업 호환성 검사 2개.
- 실행 JavaScript 3개 구문 검사 통과.
- 브라우저에서 캐릭터 표시·선택 전환, 원본 프레임 재생, 모자 업로드·표시·부착 좌표,
  애니메이션 멈춤을 확인.
- 캐릭터 PNG 10개가 작가 원본과 바이트 단위로 일치함을 확인.
- 미리보기 페이지의 인라인 스크립트 차단 문제를 외부 스크립트로 분리해 해결.
- 작은 기기 화면의 하단 설명 잘림을 수정.

제공 환경은 Linux/Chrome이다. 사용자의 실제 M1 맥북에서 Safari, 카메라, 한국어 음성,
AI 대화 속도는 이번 작업으로 확인한 것으로 간주하지 않는다. 미리보기 HTML의 브라우저
다운로드 미리보기에서 실행이 제한되면 파일을 저장하고 Safari/Chrome으로 직접 연다.

## 레퍼런스 확인

- 이전 대화에서 언급된 Unity 모음은
  https://github.com/StefanoCecere/awesome-opensource-unity 이다. 도구와 게임 프로젝트 모음이며
  캐릭터 완성품 하나를 제공하는 저장소는 아니다.
- 이전 답변에 적혔던 `Mzy-1/Pixel-Pocket`은 이번 확인에서 GitHub API 404를 반환했다.
  원래 캡처와 같은 저장소인지도 검증하지 못했으므로 구현 출처로 사용하지 않았다.
- 이번 원본: https://pixelfrog-assets.itch.io/pixel-adventure-1
- Unity에서 같은 PNG를 쓰려면 Sprite/Multiple, 32×32 Grid, Point 필터, 압축 해제,
  20 FPS Animation Clip으로 가져올 수 있다. **이번 패키지를 Unity에서 빌드한 것은 아니다.**
- Unity의 공식 Sprite Swap 설명:
  https://docs.unity3d.com/Packages/com.unity.2d.animation@12.0/manual/SpriteSwapLanding.html
