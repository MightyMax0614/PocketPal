# P1 캐릭터 업로드 오류 수정 기록

- 날짜: 2026-08-02
- 대상: `prototype/p1-web`
- 관련 이슈: #2

## 문제

아이폰 Safari에서 그림이나 사진을 선택해도 캐릭터로 적용되지 않거나, 큰 사진이 저장되지 않는 현상이 있었다.

## 원인

1. 이전 구현은 큰 이미지를 `localStorage`에 직접 저장해 Safari 용량 제한에 걸릴 수 있었다.
2. 사진 선택 후 별도의 `캐릭터로 적용` 버튼을 다시 눌러야 해 사용 흐름이 불명확했다.
3. UI에서 2D 적용과 실제 3D 변환의 차이가 충분히 명확하지 않았다.

## 수정

- 사진 선택 즉시 2D 캐릭터로 적용
- 긴 변 기준 최대 480px로 자동 축소
- WebP 우선, JPEG 대체 변환
- 이미지 본문은 IndexedDB에 저장
- IndexedDB 실패 시 localStorage 대체
- 이름은 localStorage에 별도 저장
- Safari 재접속 후 캐릭터 복원
- 지원하지 않는 이미지 형식은 스크린샷 재업로드 안내
- UI 문구를 `2D 적용`, `3D 변환은 다음 단계`로 명확히 구분

## 현재 범위

이번 수정은 **2D 캐릭터 교체 기능**이다. 메시 생성, 리깅, GLB/glTF 출력 같은 실제 3D 변환은 아직 구현되지 않았다.
