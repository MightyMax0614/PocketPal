# P1.2 Custom Character UI Specification

- 작성일: 2026-08-02
- 대상: 아이폰 Safari와 GitHub Pages P1 시제품

## 캐릭터 화면

```text
[아이 그림이나 사진 선택]
[선택 이미지 미리보기]
[캐릭터 이름]
[이름까지 다시 적용] [기본 캐릭터]

[현재 상태]
현재 상태: 별이 2D 캐릭터 적용됨
3D 상태: 3D 변환 요청이 준비됐어요

[3D 만들기] [3D 미리보기]
[job.json 저장] [원본 저장]
```

## 버튼 동작

### 3D 만들기

- 커스텀 캐릭터가 있을 때만 활성화한다.
- 로컬 브라우저에 `job.json` 내용을 저장한다.
- 상태를 `queued`로 바꾼다.
- 이 버튼 자체가 img2threejs 변환을 실행하는 것은 아니다.

### 3D 미리보기

- 현재 캐릭터 이미지로 2.5D 임시 미리보기를 연다.
- 실제 GLB/GLTF 결과 파일이 있으면 파일 선택으로 불러온다.
- img2threejs의 절차형 JavaScript 모듈은 URL 쿼리로 불러올 수 있다.

### job.json 저장

- NAS/PC 작업기에 넘길 요청 파일을 아이폰 파일 앱에 저장한다.

### 원본 저장

- 브라우저에 저장된 캐릭터 원본을 PNG 이름으로 저장한다.

## 3D 뷰어

- 한 손가락 회전
- 두 손가락 확대/축소
- 자동 회전 켜기/끄기
- GLB/GLTF 로컬 파일 불러오기
- 2.5D 결과와 실제 3D 결과를 문구로 명확하게 구분

## 상태 색상

| 상태 | 표시 |
|---|---|
| `none` | 회색 |
| `queued` | 파랑 |
| `processing` | 청록 |
| `done` | 초록 |
| `failed` | 주황/빨강 |

## 사용성 원칙

- 업로드 후 화면을 강제로 홈으로 보내지 않는다.
- 아이가 같은 화면에서 바로 `3D 만들기`를 누를 수 있어야 한다.
- 긴 처리는 아이폰이 아니라 NAS/PC가 담당한다.
