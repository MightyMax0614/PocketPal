# PocketPal P1 커스텀 캐릭터 파이프라인

- 기록일: 2026-08-02
- 현재 구현 단계: **업로드 이미지 → 2D PocketPal 캐릭터 적용**
- 다음 목표: 배경 제거 → 파츠 분리 → 2.5D → 리깅된 3D 캐릭터

## 이번 버전에서 구현한 것

1. 아이가 그린 그림이나 사진을 아이폰에서 선택한다.
2. 브라우저가 이미지를 PocketPal 화면 크기에 맞게 축소한다.
3. 캐릭터 이름을 입력한다.
4. `캐릭터로 적용`을 누르면 기존 임시 캐릭터 대신 업로드 이미지가 표시된다.
5. 캐릭터에 가벼운 대기 움직임을 적용한다.
6. 이미지와 이름을 브라우저 내부에 저장한다.
7. Safari를 닫았다 다시 열어도 같은 캐릭터가 유지된다.
8. `기본 캐릭터` 버튼으로 초기화할 수 있다.

## 현재 한계

- 아직 자동 배경 제거를 하지 않는다.
- 사진 전체가 하나의 평면 이미지로 움직인다.
- 눈 깜빡임, 입 모양, 팔·다리 움직임은 이미지에서 분리되지 않는다.
- 실제 3D 메시와 GLB는 아직 생성하지 않는다.
- 캐릭터 데이터는 현재 사용 중인 브라우저에만 저장된다.

## 다음 구현 순서

### P1.1 배경 제거

- 인물·캐릭터 영역 자동 분리
- 투명 PNG 또는 WebP 생성
- 사용자가 지우개·복원 브러시로 보정

### P1.2 2.5D 캐릭터

- 머리·몸·팔·다리 파츠 분리
- 각 파츠에 간단한 관절점 지정
- 눈 깜빡임·호흡·점프·인사 애니메이션
- 아이 그림의 원래 느낌을 최대한 유지

### P1.3 3D 초안

- 정면 그림 한 장으로 기본 메시 생성
- 가능하면 측면 그림을 추가로 받음
- 메시 두께·대칭·뒷면 생성
- 기본 스켈레톤과 리깅
- GLB/glTF 내보내기

### P1.4 3D 선물 연동

- 머리, 얼굴, 가슴, 등, 손 부착점 정의
- 모자·안경·배지·가방부터 적용
- 캐릭터가 선물을 받고 착용하는 반응 추가

## 입력 권장 조건

가장 좋은 결과:

- 흰색 또는 단순한 배경
- 정면 전신 캐릭터
- 팔·다리가 몸에서 어느 정도 떨어진 그림
- 외곽선과 색상이 명확한 그림
- 가능하면 측면 그림 한 장 추가

사진도 사용할 수 있지만, 최종 캐릭터는 사진을 그대로 입체화하기보다 사진에서 특징을 추출해 캐릭터 스타일로 변환하는 방식을 별도로 검토한다.

## 개인정보 원칙

- 아이 그림과 사진은 우선 기기 또는 NAS에서 처리한다.
- 클라우드 3D 생성 사용 시 전송되는 이미지와 목적을 보호자에게 표시한다.
- 원본, 처리본, 3D 결과물을 각각 삭제할 수 있게 한다.
