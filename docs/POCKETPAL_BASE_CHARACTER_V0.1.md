# PocketPal Base Character v0.1

- 상태: 확정
- 기준일: 2026-08-02
- 적용 버전: P1.4

## 1. 기본 방향

PocketPal의 기본 캐릭터는 하얀색 또는 아주 연한 아이보리색의 중성 인체형 바디 1종으로 시작한다.

기본 바디는 아이가 직접 얼굴, 옷, 모자, 배지, 가방, 손 소품을 더해 나만의 친구로 완성할 수 있는 빈 캔버스 역할을 한다.

캐릭터 본체를 매번 새로 생성하지 않는다. 동일한 친구의 기억과 성격은 유지하고 외형 파츠만 바꾼다.

## 2. 승인된 실루엣

- 작은 원형 머리
- 매우 짧은 목
- 어깨에서 허리까지 이어지는 둥근 몸통
- 몸 옆으로 자연스럽게 내려오는 길고 둥근 팔
- 손가락과 발가락은 표현하지 않음
- 아래에서 두 갈래로 분리되는 짧고 안정적인 다리
- 성별, 연령, 특정 동물을 강하게 연상시키지 않는 형태
- 귀, 꼬리, 뿔, 날개는 기본 바디에 고정하지 않고 꾸미기 파츠로 처리

## 3. 화면 비율 기준

전체 보이는 캐릭터 높이를 100으로 볼 때의 잠정 제작 비율이다.

- 머리: 약 33
- 목: 약 7
- 몸통: 약 54
- 다리 노출: 약 20
- 전체 어깨 폭: 약 51
- 팔 길이: 약 46

머리가 몸보다 큰 SD 캐릭터 비율로 만들지 않는다. 사용자가 승인한 참고 이미지처럼 단순한 사람형 실루엣을 우선한다.

## 4. 2D 애니메이션 파츠

P1.4 웹 시제품은 다음 파츠를 독립적으로 움직인다.

- head
- neck
- body
- left_arm
- right_arm
- left_leg
- right_leg
- left_eye
- right_eye
- left_pupil
- right_pupil
- eyelids
- mouth
- left_cheek
- right_cheek
- shadow

꾸미기 파츠는 다음 슬롯으로 분리한다.

- face: 눈, 입, 볼, 눈썹, 안경
- head: 모자, 리본, 새싹, 왕관
- body_front: 옷, 무늬, 배지
- back: 가방, 망토, 날개
- hand: 손에 드는 그림과 소품

## 5. 기본 애니메이션

항상 작동:

- 미세한 호흡
- 고개의 작은 관성 움직임
- 팔의 미세한 흔들림
- 불규칙한 눈 깜빡임
- 화면 포인터와 무작위 시선 추적

상태 동작:

- wave
- jump
- happy
- curious
- sleepy
- pet
- look-around
- talking mouth

## 6. 소울 원칙

외형은 하얀 기본 바디에서 시작하지만 캐릭터의 정체성은 다음 항목으로 형성한다.

- 아이가 지어 준 이름
- 선택한 얼굴과 옷
- 받은 그림 선물
- 다정함, 호기심, 명랑함, 차분함 등의 기본 성격
- 말투
- 아이를 부르는 이름
- 좋아하는 주제
- 저장된 기억
- 친밀도, 에너지, 호기심, 현재 기분

캐릭터는 무작위 대사만 반복하지 않는다. 시간, 기억, 아이의 입력, 성격 상태를 이유로 먼저 말을 건다.

## 7. P1.4 구현 범위

구현됨:

- 하얀 기본 바디
- 얼굴, 모자, 옷, 배지 프리셋
- 이름 저장
- 감정 및 동작 시험
- 쓰다듬기 반응
- 기억 기반 로컬 대화
- 일정 시간 후 자발 발화
- 그림을 head, face, body, badge, hand 슬롯에 올리는 시험

검증 필요:

- 아이폰 Safari에서 실제 화면 비율
- 터치 쓰다듬기 민감도
- 자발 발화 간격
- 작은 화면에서 표정 가독성
- 그림 배경 제거와 자동 슬롯 분류

## 8. 보류 항목

- 자동 생성 3D 캐릭터
- 360도 GLB를 메인 캐릭터로 사용하는 방식
- 사용자 그림 전체를 캐릭터 본체로 대체하는 방식

관련 코드는 연구 자료로 저장소에 남겨두되 P1.4 메인 사용자 흐름에는 노출하지 않는다.
