## 브라우저에서 확인한 흐름

- 첫 화면: 캐릭터와 클릭휠, 대화 도구가 빈 화면 없이 표시. 전체 화면 캡처로 겹침·잘림을 확인.
- 이름 저장: 가상 이름을 입력하고 저장 후 화면의 친구 이름에 반영.
- 기억 회상: “첫째 시험 기억: 티라노사우루스를 좋아해” 저장 → “내가 좋아하는 걸 기억해?” → 저장 내용이 답변에 포함.
- 입력: 한글 문자열 입력, Space 추가, ArrowLeft 커서 이동 후에도 입력창이 유지. 실제 macOS 한국어 IME 조합 이벤트는 미검증.
- 프로필: 둘째 선택 후 대화와 기억이 비어 있음. 첫째로 복귀하면 기존 기록 유지. 전환 중 이전 아이 데이터가 잠시 남지 않도록 화면 초기화 보완.
- 선물: 로컬 시험 PNG 선택 → 미리보기 → 흰 배경 제거 슬라이더 → 배지 위치 선택 → 저장 → 캐릭터 이미지 표시.
- 동작: 점프 버튼 후 `motion-jump` 적용 확인. 선물은 해당 머리/몸통/팔 요소 안에 부착하도록 구현.
- 새로고침: 이름·기억·착용 선물 유지.
- 클릭휠: MENU → 다음 항목 → 가운데 버튼으로 기억 화면 이동.
- AI 연결 실패 안내: 로컬 Ollama가 없을 때 실제 미연결 안내 표시.
- 시험표: 8개 체크 항목과 메모 입력 화면 표시. 결과 JSON 다운로드 파일을 확인했으며 8개 항목 모두 미체크 상태로 내보냄. 사용자 실기 시험을 대신 통과 표시하지 않음.
- 애플리케이션 주소에 해당하는 브라우저 오류 로그는 확인되지 않음. 브라우저 자체 확장 기능 메시지는 앱 결과에 포함하지 않음.

## 맥북에서 남은 시험

1. ZIP 해제 후 Finder/터미널 실행, Python 경로 확인, 포트 8765 확인.
2. 실제 Safari/Chrome 렌더링, 한국어 IME, 트랙패드 휠 제스처.
3. 실제 카메라 허용·촬영·탭 전환 시 종료.
4. 다운로드한 한국어 로컬 음성으로 TTS 재생, 볼륨·음질.
5. 실제 Ollama 모델 설치, 한국어 대화 정확도, M1 메모리 압박과 첫/후속 응답시간.
6. Wi-Fi를 실제로 끈 상태의 기본 기능, 사전 설치된 로컬 AI·음성.
7. 맥북 종료·절전·앱 재실행에 따른 저장 상태. 현재 백그라운드 알람/발화는 미구현.
8. 프레임 속도·장시간 동작·배터리 소모. 화면 모션 선호도/품질의 사용자 평가.
9. 두 카메라가 있는 스마트폰의 앞뒤 전환, AR는 다음 구현 단계.
