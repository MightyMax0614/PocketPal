# PocketPal 캐릭터 제작 방향 · 2026-09-08

## 사용자가 요청한 방향

- 갖고 싶고 교감하고 싶은 캐릭터 품질을 우선한다. 단순한 도형을 조합한 기존 바디로 되돌아가지 않는다.
- PocketPal만의 오리지널 사람형, 공룡형, 동물형 캐릭터가 모두 필요하다.
- 공룡은 토이스토리 렉스에서 느껴지는 큰 덩치, 순함, 조금 어설픈 매력과 표정이 참고 방향이다.
- 하마와 돼지 같은 체형·인상도 포함한다.
- 기존에 살펴본 Pixel Frog의 Pixel Adventure 1·2 캐릭터도 전부 함께 보관한다.
- 원화, 출처, 코드와 제작 기록은 GitHub에 저장한다.

렉스는 D1 v2의 감정·성격·체형 방향을 설명하는 참고 대상이다. 저장된 D1 v2 이미지는 PocketPal용으로 새로 생성한 디자인 시안이다. 영화 이미지나 영화 캐릭터 모델을 프로젝트 자산으로 포함하지 않았다.

## 공통 원화 스타일

따뜻한 아이보리 배경의 2D 캐릭터 원화, 분명한 실루엣, 입체감을 주는 명암, 읽기 쉬운 눈·눈썹·입, 친구마다 구별되는 체형과 색을 사용했다. 각 보드는 큰 전신 포즈와 두 가지 표정 연구를 포함한다. 오리지널 보드는 ImageGen으로 생성했다.

사람형은 얼굴·머리카락·귀·손·발과 옷의 구조가 구별되는 약 3등신 비율이다. 동물과 공룡은 종을 알아볼 수 있는 특징을 유지하고, 표정·손짓·몸짓으로 다정함과 성격을 표현한다.

## 보드별 제작 기록

| 파일 | 제작 의도 | 이후 처리 |
|---|---|---|
| `originals/first-companions-v1.png` | 사람형 H1, 긴 귀와 부채꼴 꼬리의 A1, 잎 모양 등판의 A2 제안 | H1은 다음 사람형 보드로 이어짐 |
| `originals/human-companions-v1.png` | H1 외형을 이어 가며 H2·H3를 추가. 얼굴·복장·성격을 구분 | 사람형 3종 후보 |
| `originals/dinosaur-companions-v1.png` | 티라노 D1, 트리케라 D2, 긴목 D3의 다른 체형 제안 | D1의 새로운 방향을 v2로 추가 |
| `originals/dinosaur-hippo-pig-v2.png` | 순하고 조금 어설픈 티라노 D1 v2, 하마 A3, 돼지 A4 추가 | 최신 요청 반영 시안 |

`catalog.json`의 `current_revision`은 제작 순서를 나타낸다. 사용자 최종 승인이나 캐릭터 확정을 의미하지 않는다. 원화 파일의 SHA-256·크기와 캐릭터 ID를 함께 기록하며, 최초 시안도 삭제하지 않는다.

## 현재 구현 범위

- 오리지널: 고해상도 원화 보드 4장, 중복을 뺀 10종, 정지 표정 연구.
- Pixel Frog: 24종, 원본 PNG 127개 보관. 기존 비교 화면은 비전투 동작·포즈 66개를 재생한다.
- Mac Lab: Pink Man과 Ninja Frog 선택, 두 아이별 기억·이름·그림 선물 저장.
- 오리지널의 투명 배경 자산, 옆·뒤 모습, 걷기·수면·대화 프레임, 선물 착용 리그는 아직 제작하지 않았다.

## 다음 제작 순서

1. 큰 원화뿐 아니라 실제 화면 크기에서 얼굴과 몸의 실루엣을 비교한다.
2. 우선 구현할 사람형·공룡형·동물형을 정한 뒤 정면·측면·후면의 비율과 색을 맞춘다.
3. 대기, 눈 깜빡임, 인사, 걷기, 기쁨, 수줍음, 수면, 대화의 일관된 애니메이션을 제작한다.
4. 머리·얼굴·가슴·등의 선물 위치를 정의하고 모자·안경·배지·가방 한 종류씩 착용을 확인한다. 공룡 프릴·뿔·긴 목과 동물의 큰 주둥이를 가리지 않도록 종류별로 위치를 잡는다.
5. Mac Lab의 실제 대화·기억·선물 화면에 연결하고 움직임과 새로고침 후 유지를 확인한다.

엔진 교체 자체가 원화 품질을 만들어 주지는 않는다. 현재 2D 원화를 곧바로 완성된 CSS 픽셀 애니메이션, Unity 모델 또는 3D 캐릭터로 표시하지 않는다. 픽셀 방식과 부위별 2D 리그 방식은 실제 작은 화면에서 외형을 유지하는지 비교한 뒤 선택한다.

104×62×12.0mm 기기 외형, 전후면 카메라, 평면 클릭휠, 아이별 기억, 그림 선물과 이후 3D·AR 목표는 유지한다.
