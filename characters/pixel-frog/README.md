# Pixel Frog · 원본 캐릭터 자산

**원화·원본 애니메이션: Pixel Frog.** 이 폴더는 PocketPal 오리지널 원화와 별도로 작가의 원본 배포 파일을 보관합니다.

| 배포본 | 저장한 범위 | 파일 수 |
|---|---|---:|
| [Pixel Adventure 1](https://opengameart.org/content/pixel-adventure-1) | `Main Characters/` 전체: 주인공 4종과 공용 등장·퇴장 이미지 | 30 |
| [Pixel Adventure 2](https://opengameart.org/content/pixel-adventure-2) | `Enemies/` 전체: 20종의 캐릭터 원본 | 97 |

출처는 작가가 OpenGameArt에 올린 아래 공개 ZIP입니다. 해당 배포본에 표시된 **Creative Commons Attribution 4.0 (CC BY 4.0)** 출처를 유지합니다.

- 작가: [Pixel Frog](https://opengameart.org/users/pixel-frog)
- [Pixel Adventure 1 원본 ZIP](https://opengameart.org/sites/default/files/Pixel%20Adventure%201.zip)
- [Pixel Adventure 2 원본 ZIP](https://opengameart.org/sites/default/files/Pixel%20Adventure%202.zip)
- [CC BY 4.0 라이선스](https://creativecommons.org/licenses/by/4.0/)
- [CC BY 4.0 전문](https://creativecommons.org/licenses/by/4.0/legalcode)

**변경 내용:** 이 폴더의 PNG 픽셀·파일명·애니메이션 프레임은 변경하지 않았습니다. 저장소 경로만 배포본별 폴더 아래에 배치했습니다. `provenance.json`은 각 파일과 출처 ZIP의 SHA-256을 기록합니다.

작가 원본의 공격·피격 등을 포함한 모든 캐릭터 이미지는 보존하지만, 기존 [24종 비교 화면](../../Character_Catalog.html)은 66개의 비전투 동작·포즈만 재생합니다. 화면 확대, 투명 여백 자르기, 좌우 반전은 표시 동작입니다.

Pixel Adventure의 원본 배경·지형·장애물 전체를 이 폴더에 중복 저장한 것은 아닙니다. 이 폴더의 보관 범위는 사용자가 요청한 캐릭터 전체이며, Mac Lab에서 사용 중인 배경 자산은 기존 `prototype/mac-lab/assets/pixel-adventure/`에 있습니다.

오리지널 원화는 [상위 캐릭터 목록](../README.md)에 제작 경위를 따로 기록합니다.
